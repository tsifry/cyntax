Como ativar

Três passos para ajustar o site.

Não precisa instalar nada: os ajustes são aplicados na hora, direto na página.

  1. 1

    Abra o menu

    Clique no botão redondo com o símbolo de acessibilidade, no canto inferior direito.

  2. 2

    Escolha o recurso

    Clique em uma opção da lista e o ajuste é aplicado. Para desativar, clique de novo.

  3. 3

    Restaure quando quiser

    A opção Restaurar padrão desfaz todos os ajustes de uma só vez.

Os ajustes valem para a página que está aberta. Ao mudar de página, escolha as opções novamente.

Atalhos de teclado

  • Tab avança para o próximo link ou botão
  • Shift + Tab volta para o item anterior
  • Enter ou Espaço ativa o item selecionado
  • Esc fecha o menu de acessibilidade
